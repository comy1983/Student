# 📊 منصة تحليل بيانات الطالبات الذكية (Student Data AI Analyzer)

تطبيق تفاعلي ذكي مبني باستخدام **Streamlit** و **Plotly** ومدعوم بالذكاء الاصطناعي **Google Gemini AI**، مصمم لمساعدة المعلمين والمشرفين على رفع وتحليل ملفات درجات الطالبات (Excel) واكتشاف نقاط القوة والضعف بشكل فوري وآلي.

## ✨ الميزات الرئيسية (Key Features)
* **📁 مرونة عالية:** استقبال أي ملف إكسل (Excel) دون اشتراط صيغة أو ترتيب محدد للأعمدة.
* **📊 تحليل تفاعلي:** تحويل الدرجات إلى مخططات بيانية وأعمدة تفاعلية لعرض النتائج بوضوح.
* **📈 تحليل نقاط القوة والضعف:** تحديد مستويات الطالبات تلقائياً وعرض تصنيفهن بناءً على درجة النجاح.
* **🤖 مستشار الذكاء الاصطناعي (AI):** قراءة البيانات وتقديم خطط علاجية شاملة للمتعثرات وخطط إثرائية للمتفوقات.
* **💾 حفظ التقارير:** إمكانية تحميل البيانات المصنفة كملف Excel، وتحميل خطط الذكاء الاصطناعي كملف نصي (TXT).

---

## 🚀 طريقة التشغيل والاعتماد (How to Run)

### 1. المتطلبات (Requirements)
تأكد من وجود الملفات التالية في المستودع الخاص بك (وهي مرفوعة بالفعل لديك):
* `app.py` (كود التطبيق الرئيسي)
* `requirements.txt` (المكتبات المطلوبة للتشغيل)

### 2. التشغيل المحلي (Local Run)
إذا أردت تجربة الكود على جهازك، قم بتنفيذ الأوامر التالية فيTerminal:
```bash
pip install -r requirements.txt
streamlit run app.py
```

### 3. النشر على الويب (Deployment)
يمكنك نشر التطبيق مباشرة ومجاناً عبر منصة **[Streamlit Community Cloud](https://streamlit.io)** بربط هذا المستودع مباشرة بضغط زرقاء واحدة.

---

## 🛠️ التقنيات المستخدمة (Built With)
* [Streamlit](https://streamlit.io) - لبناء الواجهات التفاعلية وسريعة الاستجابة.
* [Plotly Express](https://plotly.com) - لإنشاء الرسوم والمخططات البيانية المتحركة.
* [Google Generative AI (Gemini)](https://google.dev) - لتحليل البيانات وصياغة الخطط التربوية.
* [Pandas](https://pydata.org) - لمعالجة وتعديل جداول البيانات.
